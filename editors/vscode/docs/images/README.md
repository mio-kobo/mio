# Documentation images

## Syntax previews

`syntax-preview-dark.png` and `syntax-preview-light.png` are generated by
`scripts/generate-assets.py` using the extension's TextMate scope colors. They
are deterministic documentation previews, not screenshots of a running editor.

To replace them with real screenshots:

1. Install the VSIX in VS Code.
2. Open `examples/hello_world.mio` or another representative file that includes
   keywords, types, strings with non-ASCII text, a rune, a comment, a struct,
   an enum, and a generic function.
3. Use a dark theme and a light theme; hide unnecessary UI or use the editor's
   screenshot mode.
4. Capture a 16:9 or 1120×660 region.
5. Save the images as `syntax-preview-dark.png` and
   `syntax-preview-light.png` in this directory, keeping the same names so the
   README links continue to work.
6. Re-run `npm run check:vsix` if the images are intended to be packaged.

## Icon

`../../icon.png` is a 128×128 PNG derived from the Mio language mark. The
Marketplace requires at least 128×128 pixels. Do not replace it with the
Mio/Mochi character illustration unless separate artwork permission has been
obtained; see `../../NOTICE.md`.

## Regenerating the previews

The asset generator is a development helper and is not part of the VSIX:

```bash
python3 scripts/generate-assets.py
```

It requires Pillow and the macOS system fonts used by the script. Edit the
palette in `scripts/generate-assets.py` if the theme colors change.
