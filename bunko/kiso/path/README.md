# kiso/path

`kiso/path` 使用纯 Mio 实现稳定的逻辑路径规则。分隔符固定为 `/`，不访问文件系统，也不解析符号链接。

公开 API 包括 `join`、`join_all`、`clean`、`base`、`dir`、`ext`、`is_abs` 和 `split`。空路径清理为 `.`；连续分隔符和 `.` 会消除；相对路径开头无法抵消的 `..` 会保留；绝对路径不会越过根；除根目录外会移除尾随分隔符。隐藏文件名如 `.env` 不视为扩展名。

本版本不识别 Windows 盘符、反斜杠或 UNC 路径。宿主文件系统路径应在边界处转换；词法 `clean` 不能替代文件系统授权或安全检查。
